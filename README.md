# TRIALLI — локальная многостраничная верстка

Минимальный Vite-проект для разработки новых страниц, совместимых с текущими
общими стилями и скриптами [trialli.ru](https://trialli.ru/).

## Команды

```bash
npm install
npm run dev
npm run build
npm run preview
```

В dev- и preview-режиме Vite локально отвечает пустой корзиной на автоматический
запрос `cart.js` к `/ajax/getCart.php`. Остальные Bitrix AJAX-обработчики
намеренно не подменяются.

Повторно забрать актуальные ресурсы с главной страницы:

```bash
npm run sync:trialli
```

## Структура

- `public/vendor/trialli/` — локальная копия CSS, JS и зависимостей из CSS;
- `public/vendor/trialli/manifest.json` — источник, размер и SHA-256 каждого файла;
- `public/assets/trialli-home/` — изображения и SVG новой главной из Figma;
- `public/assets/trialli-catalog/` — изображения и SVG каталога и выдачи;
- `src/styles/home.css` — изолированные стили новой главной;
- `src/scripts/home.js` — подборщик, слайдеры, карточки и модальные окна главной;
- `src/styles/catalog-menu.css` / `src/scripts/catalog-menu.js` — четырёхуровневое
  меню каталога;
- `src/styles/catalog-results.css` / `src/scripts/catalog-results.js` — выдача,
  фильтры, сортировка, варианты отображения и корзина;
- `src/styles/parts-finder.css` / `src/scripts/parts-finder.js` — отдельный
  подборщик с desktop/mobile-представлениями;
- `src/scripts/parts-finder-data.js` — тестовый источник марок, моделей,
  двигателей, модификаций и товарных групп;
- `src/styles/page.css` — стили новой верстки;
- `src/scripts/page.js` — скрипты новой верстки;
- `pages/` — дополнительные HTML-страницы.

## Готовые страницы

- `/` — новая главная;
- `/pages/parts-finder.html` — подбор по автомобилю, VIN или госномеру;
- `/pages/catalog-results.html` — результаты подбора и каталог.

Подборщик последовательно разблокирует поля, передаёт выбранную комплектацию
или VIN в query string страницы результатов и хранит список «Мои авто» в
`localStorage` под ключом `trialliPartsFinderCars`. Данные вынесены в отдельный
модуль, поэтому вместо него можно подключить ответы существующего backend API,
не меняя разметку и стили.

Скачанные файлы поставщика не редактируем вручную. При синхронизации абсолютные
ссылки `url(...)` внутри CSS автоматически переводятся на локальный
`/vendor/trialli/`, чтобы шрифты и изображения работали без исходного сервера.
Собственные CSS и JS подключаем после vendor-файлов. Для новых классов желательно
использовать свой префикс (в примере — `tpl-`), чтобы не пересекаться с классами
действующего сайта.

Главная страница использует префикс `tri-home-` и корневой контейнер
`[data-tri-home]`. Новые шапка, мобильная навигация и футер собраны по макетам
Figma и не зависят от старых классов `.header` и `.footer`.

Каталог и подборщик дополнительно изолированы префиксами `tri-catalog-menu-`,
`tri-results-` и `tri-finder-`. Общие vendor-стили подключаются раньше
собственных, а vendor-скрипты на новых страницах не загружаются: это исключает
обращения старого JavaScript к отсутствующим DOM-узлам.

Скрипт синхронизации делит найденные на главной ресурсы на общие и
страничные. Все они сохраняются локально, но в стартовых HTML подключены только
общие. Страничные ресурсы можно добавить из `manifest.json` по необходимости.
